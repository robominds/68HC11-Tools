# 6811 Include Files

This repository contains include files for Motorola 6811 microcontroller development using the [as11pp preprocessor](https://github.com/robominds/AS11PP).

68HC11 Compiler: https://github.com/JimInCA/motorola-6800-assembler

## Files

- `bits.inc` - Bit manipulation definitions
- `genconst.inc` - General constants
- `intvec.inc` - Interrupt vector definitions
- `rege1.inc` - Register definitions (E1 variant)
- `regf1.inc` - Register definitions (F1 variant)
- `regf1cln.inc` - Clean register definitions (F1 variant)
- `sciio.inc` - Serial Communications Interface I/O definitions
- `serio.inc` - Serial I/O definitions

## Usage

These files are designed to be used with the as11pp preprocessor for 6811 assembly programming.
